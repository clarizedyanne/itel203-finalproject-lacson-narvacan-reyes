# itel203-finalproject-lacson-narvacan-reyes
A final project for ITEL 203, ITEP 204, and ITEP 206. This serves as a repository for the website to be passed, in fulfillment of the requirements for ITEL 203 (Web Systems and Technologies). The website is a convenient and efficient online menu configuration and reservation placement for a local restaurant in San Pablo City, Laguna.
